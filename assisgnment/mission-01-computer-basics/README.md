# Mission 1: Know your computer

## Task 1.1: Trace one activity using IPOS

Activity: typing and saving a document.

| Stage | What happens in my example | Hardware or component |
|---|---|---|
| Input | I press keys and the keyboard sends the letters to the computer | Keyboard |
| Processing | The CPU works out which letters were typed and RAM holds the text | CPU and RAM |
| Output | The letters appear on the screen | Monitor |
| Storage | When I click Save, the file is written to the drive | SSD |

How the activity moves: the keyboard sends my typing in, the CPU and RAM process it, the screen shows it, and saving puts the file on the SSD so it stays after shutdown.
