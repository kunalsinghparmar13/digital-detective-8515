# Mission 0 — Setup

## 1. Task / objective

Set up the Digital Detective repository on GitHub with a folder and README for every mission.

## 2. Work completed

- Created the repository `digital-detective-8515` on GitHub.
- Created the mission folders (`mission-00-setup` to `mission-08-final-report`) and the `evidence/` folder.
- Added a README file in every folder and pushed everything to GitHub.
- Checked the installed versions:
  - Python version: Python 3.15.2
  - Git version: git version 2.55.0

## 3. Commands / tools used

| Command / tool | Purpose |
|---|---|
| `mkdir` | Create the mission folders |
| `touch README.md` | Create an empty README in each folder |
| `python3 --version` | Check the installed Python version |
| `git --version` | Check the installed Git version |
| `git add`, `git commit`, `git push` | Save the structure and upload it to GitHub |
| VS Code | Edit the README files |
| GitHub | Host the repository online |

## 4. My understanding

A repository is a project folder that Git tracks. Keeping one folder per mission makes the work easy to find and review, and pushing to GitHub keeps a copy online.

## 5. Difficulties faced

The difficult task in this mission was creating multiple READMEs in multiple folders.

## 6. How I resolved them

I created the folders first with `mkdir` and then went into each one to create its README, checking with `ls` that every folder had one.
